## VI. FILING STRATEGY FOR CASES 002-042

### Priority Tiers (from Master Index)

**Tier 1: File Immediately**
- Cases with approaching statute of limitations
- Cases with critical financial impact
- Criminal cases requiring immediate action

**Tier 2: File After Case 001**
- Major insurance cases
- Banking cases with clear liability
- Identity theft and threats (if not Tier 1)

**Tier 3: File as Details Develop**
- Cases requiring more information
- Cases with longer statute of limitations
- Cases that may be resolved informally

### Coordination Strategy

**Option A: Individual Cases**
- File separate complaint for each case
- Advantages: Focused, appropriate forum
- Disadvantages: Multiple filings, more complex

**Option B: Consolidated Cases**
- Group related cases together
- Advantages: Efficiency, shows pattern
- Disadvantages: Complexity, jurisdictional issues

**Option C: Phased Approach** (RECOMMENDED)
- Phase 1: Case 001 (primary case)
- Phase 2: High-priority cases (002, 003, 017, 018, insurance cases)
- Phase 3: Medium-priority cases as details emerge
- Phase 4: Lower-priority cases as appropriate

**Decision:** Attorney Erik Nydert to determine optimal strategy based on:
- Statute of limitations calculations
- Available evidence
- Potential recovery amounts
- Resource allocation
- Settlement prospects
