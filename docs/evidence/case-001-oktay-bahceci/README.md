## Evidence Organization

### Medical Records Folder
Store all medical and psychiatric documentation:
- Psychiatric hospital admission records
- Treatment notes and progress reports
- ADHD medication prescriptions
- Medical marijuana prescription (USA)
- Shoulder pain treatment records

**Naming Convention:**
```
MED-[DATE]-[TYPE]-[DESCRIPTION].pdf

Examples:
MED-2018-01-15-Psychiatric-Admission.pdf
MED-2019-06-20-ADHD-Prescription.pdf
MED-2020-03-10-Treatment-Notes.pdf
```

### Employment Records Folder
Store all work-related documentation:
- Resume/CV

```
EMP-[DATE]-[TYPE]-[DESCRIPTION].pdf
```

## Chain of Custody

For EACH file you upload, create a GitHub "Evidence Tracking" issue:

1. Go to Issues → New Issue → Evidence Tracking
2. Fill in:
   - Evidence ID (e.g., EV-001, EV-002)
   - Date obtained
   - Source (where it came from)
   - Current location (path in this repository)
   - Description of what it is
   - How it's relevant to the case

3. Link the issue to related Incident Reports

## Working With Evidence

### When You Add a File:
1. Upload to appropriate folder
2. Use proper naming convention
3. Create Evidence Tracking issue
4. Note in issue where it came from
5. Link to related Incident Reports
6. Update the checklist above

### Before Sharing with Attorney:
1. Organize all files by category
2. Create master evidence list
3. Ensure all files are properly named
4. Verify chain of custody documented
5. Package for attorney review

### Before Court Submission:
**ONLY WITH ATTORNEY APPROVAL:**
1. Attorney reviews all evidence
2. Determines what's admissible
3. Prepares exhibit list
4. Handles authentication
5. Files with court per proper procedures
