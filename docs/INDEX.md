## Documentation Hierarchy

### Level 1: Individual Tracking (GitHub Issues)
**Purpose:** Track discrete items with searchable, linkable, time-stamped entries

**Components:**
- Incident Reports (each harmful event)
- Evidence Tracking (each piece of evidence)
- Damages Claims (each damage category)
- Timeline Entries (each significant event)

**Best For:**
- Ongoing tracking
- Quick updates
- Cross-referencing
- Collaboration
- Status tracking

### Level 2: Formal Documentation (Markdown Files)
**Purpose:** Create comprehensive, court-ready documentation

**Components:**
- Case files (complete case documentation)
- Evidence catalogs (organized evidence records)
- Timeline compilations (chronological narratives)
- Legal filings (court documents)

**Best For:**
- Formal presentation
- Legal counsel review
- Court submission
- Comprehensive overview
- Professional format

### Level 3: Knowledge Base (Wiki)
**Purpose:** Provide guidance, standards, and reference materials

**Components:**
- How-to guides
- Best practices
- Legal concepts
- Templates
- Reference materials

**Best For:**
- Learning the system
- Standardizing approach
- Understanding legal concepts
- Finding examples
- Maintaining consistency

## Cross-Reference System

### Linking Strategy

**GitHub Issues to Documentation:**
- Include issue numbers in documentation
- Link to relevant issues in case files
- Reference issues in timelines

**Documentation to GitHub Issues:**
- Link to evidence issues from documents
- Reference incident reports in case files
- Connect timeline docs to timeline issues

**Internal Documentation Links:**
- Cross-reference related sections
- Link evidence to incidents
- Connect damages to timeline events

### Naming Conventions

**Issues:**
```
[TYPE] Brief descriptive title
Examples:
[INCIDENT] Unauthorized charge on credit card
[EVIDENCE] Email from defendant dated 2024-01-15
[DAMAGES] Medical expenses for injury treatment
[TIMELINE] Initial contract signing meeting
```

**Files:**
```
[CASE-ID]_[DATE]_[TYPE]_[DESCRIPTION].[ext]
Examples:
CASE001_2024-01-15_EMAIL_Contract-Negotiation.pdf
CASE001_2024-02-03_PHOTO_Property-Damage.jpg
```

**Directories:**
```
case-[ID]-[brief-name]/
Examples:
case-001-employment-discrimination/
case-002-contract-dispute/
```

## Glossary of Terms

**Incident:** A specific harmful event or problem
**Evidence:** Any material that tends to prove or disprove facts
**Timeline:** Chronological record of events
**Damages:** Losses suffered (economic and non-economic)
**Chain of Custody:** Record of evidence handling
**Discovery:** Pre-trial exchange of information
**Deposition:** Oral testimony under oath before trial
**Motion:** Request for court ruling
**Plaintiff:** Party bringing the lawsuit
**Defendant:** Party being sued
**Statute of Limitations:** Deadline for filing lawsuit
