- **Documents:** Contracts, emails, letters, forms
- **Financial records:** Bank statements, bills, invoices

- **Correspondence:** All communications with parties

#### 4. Damages
- **Financial losses:** Exact amounts with documentation

- **Emotional harm:** Description of suffering
- **Other damages:** Any other harm suffered

#### 5. Current Status
- **Ongoing issues?** What's happening now
- **Deadlines:** Statute of limitations, response dates
- **Prior actions:** What you've already done
- **Communications:** Recent contact with parties
