## 🛠️ How to Use This Repository

### For Case Management

1. **Track Progress**: Use [GitHub Projects](https://github.com/xaoex/.cases/projects)
2. **Manage Tasks**: Create and update [Issues](https://github.com/xaoex/.cases/issues)
3. **Document Evidence**: Add to evidence inventory
4. **Monitor Deadlines**: Check timeline project board
5. **Prepare Filings**: Use document templates

### For Documentation

1. **Case Files**: Store in `/docs/cases/`
2. **Evidence**: Catalog in `/docs/evidence/`

4. **Legal Filings**: Prepare in `/docs/legal-filings/`
