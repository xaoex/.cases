## Case Status Definitions

- **Draft:** Case is being prepared but not yet filed
- **Filed:** Case has been submitted to the court
- **Active:** Case is in active litigation
- **Discovery:** In discovery phase
- **Pre-Trial:** Preparing for trial
- **Trial:** Currently in trial
- **Pending Decision:** Awaiting court ruling
- **Appealed:** Case has been appealed
- **Settled:** Case resolved through settlement
- **Won:** Favorable judgment received
- **Lost:** Unfavorable judgment received
- **Dismissed:** Case dismissed by court
- **Closed:** Case concluded (any reason)

## Getting Started

To add a new case:

1. Copy the template from `/templates/CASE_TEMPLATE.md`
2. Save it in `/cases/` with format: `CASE-XXX_short-description.md`
3. Update this registry with case details
4. Create a GitHub issue for tracking
5. Update relevant sections as case progresses
